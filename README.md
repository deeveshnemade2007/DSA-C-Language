# DSA in C Language

Welcome to my **Data Structures and Algorithms (DSA) in C Language** repository! 👋

This repository contains my C programs and practice problems as I learn and improve my programming skills, problem-solving abilities, and understanding of data structures and algorithms.

## 📚 About This Repository

The purpose of this repository is to practice DSA concepts using the C programming language, from basic programs to advanced data structures and algorithms.

## 🗂️ Topics Covered

- **C Programming Basics** – Variables, data types, operators, input/output, and control statements.
- **Arrays** – Array operations and basic problem-solving.
- **Strings** – String manipulation and operations.
- **Functions and Recursion** – User-defined functions and recursive programs.
- **Pointers** – Pointers and memory handling.
- **Linked Lists** – Singly linked lists and insertion/deletion operations.
- **Stacks and Queues** – Basic implementation and operations.
- **Trees** – Binary trees, Binary Search Trees (BST), and tree traversal.
- **Searching Algorithms** – Linear search and binary search.
- **Sorting Algorithms** – Basic sorting techniques.
- **Problem Solving** – Practice programs and logic-building exercises.

*Note: Topics will be added as I continue learning and implementing them.*

## 🚀 Getting Started

### 1. Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/deeveshnemade2007/DSA-C-Language.git
```

### 2. Navigate to the Project Folder

```bash
cd DSA-C-Language
```

### 3. Compile a C Program

For example, if your file is named `main.c`, run:

```bash
gcc main.c -o main
```

### 4. Run the Program

**Windows:**

```bash
.\main.exe
```

**Linux / macOS:**

```bash
./main
```

Replace `main.c` with the name of the C file you want to compile.
